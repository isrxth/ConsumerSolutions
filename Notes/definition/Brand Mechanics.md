# Brand Mechanics

* **Definition:** The neuro-cognitive transmission process by which external sensory markers encode integrated value experiences into consumer memory stores [L7 Slide 10, Slide 11].
* **Anatomy:**
  * **Markers (Brand Elements):** Sensory stimuli (visual, auditory, tactile, olfactory, gustatory) [L7 Slide 11].
  * **What is Marked:** Integrated combinatorial value experiences [L7 Slide 10].
  * **Process of Marking:** Encoding associations and assimilations into cognitive memory to generate expectations and identification [L7 Slide 11, Slide 14].
