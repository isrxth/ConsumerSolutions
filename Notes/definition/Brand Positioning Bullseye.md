# Brand Positioning Bullseye

* **Definition:** An architectural framework defining the competitive space and perceptual territory an access handler occupies in consumer memory [L7 Slide 12, Slide 30].
* **Core Components:**
  * **Frame of Reference (FOR):** The target market and competitive context [L7 Slide 30].
  * **Points of Parity (POP):** Baseline associations shared with competitors (maps to [[Enabler]]s) [L7 Slide 30].
  * **Points of Difference (POD):** Unique, highly compelling associations that differentiate the brand (maps to [[Differentiator]]s) [L7 Slide 30].
